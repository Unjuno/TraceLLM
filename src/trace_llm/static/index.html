2つの保存済みモデルが必要です。

指標の読み方と制約

「初回」は、現在の系譜のページIDと本文の完全一致ハッシュによる分類です。編集したページや同じ文章の再投入は、初回のグラフに混ぜません。近似重複は未検査です。

保持は、過去に学習した資料の一部を同じジョブの前後で比較します。正の差はその資料での誤差増加を意味しますが、統計的に確認された忘却ではありません。処理中に対象ページが削除された場合、その保持評価は使いません。

グラフと表は最近120件、上の集計は選択した期間・系譜全体です。別分岐を含むときは、共通の学習を重複した独立観測とはみなせません。使用中のモデルは7日を過ぎても保持します。復元は「学習履歴」で行います。

この画面は計測の読み取り専用です。CPU時間はプロセスで消費した時間であり、使用率ではありません。JSON保存に本文・ページ名・生成文は含めません。記録された失敗と欠損は隠さず表示し、健全性スコアは作りません。
