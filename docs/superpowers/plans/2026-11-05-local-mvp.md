# TraceLLM Local MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Ship a runnable, tested local journal with real scratch GPT learning.
**Architecture:** Immutable page revisions -> durable jobs -> one trainer -> atomic
checkpoint publication. FastAPI serves the page UI and JSON endpoints.
**Tech Stack:** Python 3.11+, PyTorch CPU FP32, FastAPI, SQLite, plain HTML/CSS/JS.
**Spec:** docs/architecture.md

## Global Constraints
Only user-authored page bodies train; 7-day checkpoint retention except current;
no secrets/data/model binaries in Git; one application process; no pretrained model.

## Review Focus
Short UTF-8 pages, partial final batches, duplicate gestures, crash/publication
boundaries, restore-vs-queued-training conflicts. Each is exercised by tests.
